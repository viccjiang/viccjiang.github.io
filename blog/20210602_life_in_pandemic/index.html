疫情下的生活，重新找回節奏

By Jiang 02 June 2021

被迫按下暫停鍵，在此刻停下腳步，認真思考下一步

五月一樣延續著四月剛養成的好習慣，持續早睡早起、每日學習、每日閱讀，每週六日下午繼續去上台大網頁設計進階班，這是我二刷這堂課了，因為去年上的那次根本聽不懂，所以跟不上進度，半途就直接放棄，最後還是有硬著頭皮有上完，但就是聽不懂… 今年這次去上，至少有 75% 聽得懂，也跟得上，覺得有事先上過六角學院 JS 直播班真的有進步，以下是台大的課綱，基本上六角學院 JS 直播班都有教到，會想去台大上課是因為實體臨場感以及需要鞭策，另外也報名了台大實體 Figma 的課，但因為疫情因素現在全面改為線上課程，然後台大線上課程的系統做的也算不錯，也滿好操作的，只是改為線上課程讓我的惰性又萌發了…

台大網頁設計進階班 課程綱要：

  1. 建置開發環境、認識開發工具操作方法
  2. JavaScript 基礎入門 (1)：變數宣告、資料型別、函數使用
  3. JavaScript 基礎入門 (2)：條件控制、迴圈、網頁元件事件綁定
  4. JavaScript 進階概念 (1)：物件與陣列、JSON資料的處理
  5. JavaScript 進階概念(2)：JavaScript資料非同步處理，如何從後端API取得資料
  6. 使用套件開發：學習如何使用jQuery
  7. 結合網頁存儲API應用：實作一個簡單的網站購物車
  8. 串接Firebase相關服務API實現動態資料網站
  9. 透過Node.js開發網站：學習Express框架建置網站

正在進行 — 五月份：VUE3課程、BS5直播班、台大網頁進階班
預計進行 — 六月份：VUE3課程、BS5直播班、程式體驗營

本以為一切的計畫能夠順利進行，但到了五月中旬，台灣疫情大爆發，無限絕望的末日感，伴隨著莫大的焦慮與恐慌，取消了很多活動，台灣也立即進入了三級警戒，路上的行人變少、商家不能開店、失業人口驟增、很多公司開始 WFH、大眾運輸減量、線上商機爆棚、物流業者吃不消、菜價飆漲等… 大家的生活產生了劇烈改變，想認真的吸一口呼吸空氣都變得奢侈，每天都處在緊張恐慌的情緒底下，學習的心情也開始受到影響，有點分心，坐立難安，這個影響至少持續了兩週到五月底，必須開始尋求紓緩的管道，在這個疫情底下，必須學會持續專注能夠控制的事情，重新找回生活的節奏，積極面對這個既定的事實已經發生，回想去年疫情爆發時還沒有像今年這種巨大末日感，但今年不一樣，因為病毒變種了，變得更加嚴峻、擴散的更快，大家的心情也大受影響！

感到巨大的焦慮，主要有這幾項因素：

健康影響 — 害怕被染疫社交關係 — 無社交活動情感因素 — 家庭裡關係經濟來源 — 害怕被失業不確定感 — 未來在哪裡

專注在可以控制的事情上，專注於呼吸，專注於控制情緒，專注於生活上安排，若還是覺得生活被打亂，可以先訂定行事曆，照著行事曆的時程進行每件事，可以消除大部分未完成事情的焦慮！

居家防疫的每一天，真的悶到極限，可以安排自己每一天有不同的主題活動

除了早上下午學習之外，都是安排自己晚上做一些以上舒壓的事情，緩解學習的焦慮及疫情的恐慌，疫情造成生活的不便，也造成很多人的生活、工作在此時被迫暫停，但也是檢視自己狀態最好的時機，在社群裡看到很多學員都是因為疫情工作受到影響、被資遣、被失業、待業中、畢業即失業的窘境，大家很多狀況都是一樣的。

人生中有多少機會是這樣被迫按下暫停鍵，在此刻停下腳步，認真思考下一步，也許是另一個契機！

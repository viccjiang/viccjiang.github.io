Vue 作品實戰班 - 2022 春季

Jiang 2022 年 3 月 9 日 約 14 分鐘閱讀

這是 2022 年第一季的學習檢視

先前已經參加六角學院的幾個直播班、體驗營，也結交到不少正在努力轉職的朋友( 雖然都是網友沒見過面，但大家都在朝一樣的路前進 )，再加上很喜歡直播班的上課氣氛還有社群的各種討論，加上每週的任務練習，對新手轉職有非常大的幫助，在上課的過程中可以不斷的提問各種問題，因為你的問題也會是別人的問題，社群裡的老師、助教跟學員們都很熱心地回覆，這次的直播班氣氛討論度更加熱絡，不少問題也在這種討論過程中，解決不少課程中遇到的學習雷點。

2022 第一季來學 Vue，之前有學了一些基礎 ( 沒認真學好 QQ )，但這次還是卡在元件傳遞 ( 唉，尤其是在 props emits emitter … 傳來傳去的頭都昏了，好多指令學不完，但至少比第一次學習 Vue 時來的快，重點是要多練習、多打 code、加深肌肉記憶還要印在腦海裡，印象比較深刻的是第六週開始用 Vue Cli 起專案，要從 web 轉到 Vue cli 一開始也是有點卡不習慣，元件也拆分出來，檔案變越來越多，然後元件又傳來傳去的更複雜了，但是開發速度是變快滿多的，開發環境的話，因電腦先前已經裝了 node 16 ，老師說支援度較高的是 node 14，但若是裝了 16 就不要卸載了，若真的要卸載，要記得卸載乾淨，但我選擇不卸載，想說先順利度過這次直播班，之後要卸載再來卸吧。

我的開發環境：

node v16.13.1

vue/cli 4.5.15

npm 8.1.2

在這學習的過程中，記錄了很多遇到的困難點，光是想要參考助教的 github code 就 run 不起來，因為 node 16 已經改為 dart-sass，不同的 node 版本需要安裝不同的 node-sass ，而且 16 版本 node-sass 已廢棄，改使用 Dart Sasst，而 Dart Sass在 npm 中名稱就是 sass ，目前解法參考了 這篇文章 簡單來說就是

1. 解除安裝原有的node-sass與sass-loader

npm uninstall node-sass sass-loader

2. 升級專案所有安裝的依賴

npm update

3. 安裝 sass-loader（10.x版本）與 sass ( webpack 版本是 5.10.0 )

npm install -D sass-loader@^10 sass

4. 再次npm run serve

然後就順利開啟了 ( 耶~ 灑花啦

更新node-sass另外還查到別的方式 npm install node-sass@npm:sass 但不太確定是用在什麼情況，反正我都嘗試過了，檔案 run 的起來就好 !!!

關於 Vue 的樣式 bootstrap 客製化可以這樣做，要客製化，必須引入以下幾個東西，順序不可以更動，一定要這樣


引用 Ray 助教的比喻，真的比較好懂

要客製化，必須引入以下幾個東西，順序不可以更動，一定要這樣

1. Bootstrap 工廠 => 
@import "../node_modules/bootstrap/scss/functions";

2. Bootstrap 電力、要產出的產品、需求 => 
@import "../node_modules/bootstrap/scss/variables";

3. Bootstrap 設備 => 
@import "../node_modules/bootstrap/scss/bootstrap";
    
而設備可以依據需求自己引入，例如 Card 、Download 等等等等，在此一率直接引入  Bootstrap 整包 @import "../node_modules/bootstrap/scss/bootstrap";
    
因此 1.2 是必備引入，沒有任何原因以及為什麼，這就是順序，你沒有工廠，先有電力產品也沒用 ~

再來覺得最有趣的是 Vue Cli ，但也採了很多雷 XD 尤其是 eslint ( 噴錯噴好噴滿 ~

Vue Cli 使用 npm 安裝
  1. 安裝 Node.js https://nodejs.org/en/
  2. Node js 版本 node -v
  3. npm 版本 npm -v
  4. https://cli.vuejs.org/zh/guide/installation.html
  5. npm install -g @vue/cli
  6. vue -V （這裡要注意是大寫Ｖ）
  7. 能看到 Vue 版本就是 Vue Cli 安裝完成
  8. 接著進入資料夾路徑 cd 資料夾路徑也可以直接拉資料夾進去
  9. 若要停止行為，可以 ctrl + c 來停止終端機
  10. 创建一个项目 vue create 輸入資料夾名稱 https://cli.vuejs.org/zh/guide/creating-a-project.html#vue-create
  11. 建立項目後，會進入這個專案 Vue Cli 的設定
  12. 選擇 manually select features 手動建立環境
  13. 選擇 Choose vue version / Babel / Router / CSS Pre-processors / Linter
  14. 選擇 Vue 3.x 版本
  15. 選擇 Router 要選 n
  16. node16 選擇 Sass 套件需選擇 “Sass/SCSS (with dart-sass)” 方可運作
  17. node14 選擇 Sass/SCSS (with node-sass)
  18. ESLint + Airbnb（高） 或是 Stardard (低)
  19. Lint on save
  20. In dedicated config files
  21. save preset 選擇 N
Vue Cli 運行方式
  1. 接下來就會開始安裝
  2. 安裝完用 vscode 開啟 create 的那個專案資料夾
  3. 打開終端機 ctrl 加 、（反引號）
  4. 輸入 npm run serve 環境運行
  5. 運行成功
  6. 運行成功後，先務必進行建立環境變數設定 .env 檔案

Vue Cli 安裝成功後，能開起來就滿滿的成就感了阿 RRR ~ ( 容易滿足的孩只 )

再來是 Github Page 部署的問題，老實說如果在這階段之前沒學過 git 的同學，可能真的比較吃力，因為可能會噴一堆奇怪的錯 ，初學者光看到噴一堆錯就會很緊張，這次直播班比較常犯的錯大概就是 main 跟 master 打錯了或是遠端設定 https / ssh 沒搞清楚，之前上切版班時我就是屬於超緊張的人，而且那時候還遇到 Github 改版問題要改用申請 token 金鑰才能用 ( 我沒用 SSH )，也好險之前經過切版班的上傳部署洗禮，了解 Github Pages 如何部署，以及部屬流程運作，像是之前沒學過一鍵部署，這次除了老師有錄影片教學之外， Ray 助教也有 文章教學，覺得真的好佛心呀，Ray 助教的部落格滿滿的寶藏，可以慢慢挖

一鍵部署指令：sh deploy.sh

  1. cd進入專案資料夾
  2. 用 cli 建立新專案vue create + 專案名稱
  3. cd進入新建的資料夾
  4. 建立完成code .開啟 vscode
  5. 將專案跑起來npm run serve
  6. 到 github 新增專案 repo ( 複製儲存庫名稱 )
  7. 回到 vscode
  • 新增 vue.config.js 資料夾，在 vue.config.js 中設置正确的 publicPath
module.exports = {  publicPath: process.env.NODE_ENV === 'production'? '/github repo 儲存庫名稱/'     : '/' }
  • 本地端程式碼，先部屬到儲存庫用網頁上第二個框來執行
  • 另外要要改成用 master (先看自己的終端機顯示什麼 main 或 master )
// 要用 HTTPS 的形式
git remote add origin [儲存庫網址]

// master 
git push -u origin master

// 執行完可以先到 repo 看專案有沒有上傳成功

8. 先回到專案資料夾根部

  • 在專案裡新增一個資料夾 deploy.sh
#!/usr/bin/env sh

# 当发生错误时中止脚本
set -e

# 构建
npm run build

# cd 到构建输出的目录下
cd dist

# 部署到自定义域域名
# echo 'www.example.com' > CNAME

git init
git add -A
git commit -m 'deploy'

# 部署到 https://<USERNAME>.github.io/<REPO>
git push -f <https://github.com/[帳號]/[儲存庫名稱].git> master:gh-pages

cd -

9. 設完就可以執行 指令為sh deploy.sh

10. 若有更新，要上傳怎麼辦?

git add .
git commit -m "update / fix something"
git push
sh deploy.sh

然後 API 的 CRUD 是重複最多次的學習動作，GET / POST / PUT /DELETE，需要注意的是 axios 的字眼會被改為this.$http.方法的這種形式來串 API，犯最多錯誤的大概就是方法打錯、沒加斜線、路徑錯誤之類的 …

這次學習過程裡，花最多時間的大概就是一直在除錯吧，除了 ESLint 會一直報錯之外，路徑常打錯也是問題之一，印象最深刻的除錯就是某天心血來潮改了個檔名，結果之後的每個檔案都打不開了，明明前一天都還好好的，隔天就全壞，我不相信，所以一整個下午一直在找錯誤，npm run serve 之後出現 ERROR 主要提示文字是

WebpackOptionsValidationError: Invalid configuration object. Webpack has been initialised using a configuration object that does not match the API schema.

這段字查了超久，一開始還以為是啥 webpack 配置問題，就往這個方向去查，結果重點在更後面的警告文字

contains exclamation mark (!) which is not allowed because it's reserved for loader syntax

debug 3~4 小時，終於找到答案，結果是檔案路經中不能有驚嘆號 … 我哭阿 ~ 然後我應該早點把那「整段」警告丟到翻譯去看，就不會花這麼多時間惹 QQ

噢，忘了提到最重要的一點，六角的助教服務真的好到沒話說，通常我都是先嘗試自己找答案，超過一定時間沒解開時就會提問，這次直播班我也是極盡所能的善用助教服務，只要卡到陰，不對，是卡程式碼，大概超過 30 分鐘，就會開始焦慮，就會思考要不要提問，但有時候我寫完敘述問題點要提問時，就又解開了 ( 這真的是謎團 ~ 發現都是自己犯了個小錯誤導致，像是 http method 打錯或是 帶錯參數 之類的這種小錯誤

助教服務，是一個很大的支持系統，不用怕笨問題，只怕你不問。

這次最棒的是學員間的所有討論都不再是使用 slack 啦，因為 slack 都不能保留同學討論的資訊，課程結束後會隨著時間消失，而這次直播班開始導入 Discord ，所以資訊終於都有被保留下來，這些討論串也幫助了我很多時刻，像是部署的這個大關卡就很多人卡關發問，我也間接在其中獲得資訊，在部署時就順利許多，還有各種的作業問題，大部分都可以在討論串獲得解答。

再來是這次直播班我比較在意的是大家每天在頻道上面提問的問題，經過先前幾次直播班的經驗，通常大家提問的問題都是我接下來會碰到的問題，所以，大概第四週之後我就開始每天在頻道上面蒐集問題，只要有人提問 Discord 就跳通知，我就會立刻看問題，比較像是在蒐集情報吧，掌握資料越多，之後遇到問題時解題的方向就會較明確 ~

其實真的滿建議大家要看頻道上討論的話題，可以學到相當多新的知識點 !!!

沒想到 8 週就這樣結束了 ? 沒了 ? 也過太快啦，Vue 燒腦的程度也真的很誇張，在進入 Vue 框架前，真的要把 JavaScript 學好再來，不然中間會一直卡一直查，好險老師加碼了很多場作業直播、助教也每週在加碼補充，這次也算是學得比較扎實了，至少看得懂 (參考) 別人的程式碼 ，然後優化自己的程式碼！

跟以往不同的是，這次直播班，我的筆記量變多了 ，之前根本沒在做筆記(懶~)，所以上過一次就忘掉，所以我不相信自己的腦袋，所以還是稍微做點筆記加深一下自己印象會比較妥當，還是建議同學有時間可以稍微做點學習上的紀錄！

如何轉職前端工程師、人生/職涯規劃

2/17 職涯規劃分享會內容介紹：

  • 卡斯伯介紹 clubhouse
  • 這次分享活動的互動方式
  • 職涯提問與解惑

問題1：抓周小程式應用，如何規劃、有遇到什麼問題 ?

開發規劃：
user story 釐清需求，定義目標，使用場景
wireframe 使用到的技術 ex.swiper 輪播

技術上的分享：

  • 本工具是直接使用 ES modules 的 import / export，可以直接引入外部套件，如：swiper, js
  • 透過這種方式，HTML 僅會只有單一的進入檔案（all.js），其餘都是外部載入
  • 現在許多套件都有提供 ES modules 的形式，如 swiper 可以看到 esm.browser 就是給瀏覽器使用的 ES modules
  • 目前主流瀏覽器（約 90%）大多可支援 ES modules，不需要另外編譯
    如果對於 ES modules 在瀏覽器上的應用
    可參考以下範例：
    https://github.com/Wcc723/Catch-week/

問題2：遇到困難，一面以後，沒有二面的機會，不清楚作品要如何優化到錄取標準 ?
可以先參考六角學院的履歷健檢，除了作品以外，還須讓面試官感受到熱情，或是撰寫部落格，或是多幾個 side project ex.口罩地圖、新冠肺炎資訊

問題3：平面美工 直接跳 UI，很多人開始轉換跑道 ?
同學觀點：看到很多平面設計直接轉UI或是網頁或前端，因為軟體業的前端一直都缺人，薪水高一點，且較不易被取代
UI/UX 通常是綁在一起，老闆心態當然是想找到一個人可以統包
而且設計的工作，薪水很不優秀… 大家都想跳槽
工程師的產值跟設計比起來，產值較高，設計較不被受尊重

  • 想請問 UI 或 前端是不是差很多
    通常要看公司規模
  • 如何評估自己的能力是否可以開始找工作
    作品集要有，看產業別，規劃職涯
    也可以參考六角學院的 輔導就業

UI 設計師：

主要工作：使用繪圖軟體進行網頁設計及畫面上的編排
必要技能：UI 繪圖軟體、美感
適合科系：美術設計相關科系
課程選擇：Adobe XD、UI 設計入門（UI 設計組合包）

網頁設計師：

主要工作：將設計稿透過 HTML、CSS 切版完成，以及製作網頁上的基本動態效果
必要技能：HTML、CSS、RWD、Bootstrap
適合科系：美術設計相關科系
課程選擇：HTML、jQuery、RWD、Bootstrap 四門課程（網頁設計組合包）

前端工程師：

主要工作：網頁設計師的工作內容，以及透過 JS 串接資料完成更複雜的網頁動態
必要技能：HTML、CSS、JS、AJAX、前端框架
適合科系：不限制
課程選擇：網頁設計師組合 + JS、JS 核心、VUE（前端組合包）

問題4：寫 Blog，面試加分的幅度大概是多少？
我在youtube上有找到這部影片 可參考這部影片 有講到很多寫部落格的好處
寫部落格雖然很花時間，但讓面試官有參考價值，了解個人特質，是否擁有熱情
卡斯伯老師認為的學習層級：僅看過課程 (印象) -> 作品集有動手做(加深記憶點) -> 撰寫部落格 (增加記憶點) -> 擔任講者分享議題 (最具意義)

問題5：工程師接案的可行性

  • 轉職前有接案，是否有加分
    轉職前不一定
  • 有工作是否適合接案
    有可行性，但要看公司
  • wordpress 行情似乎比較好
    這也不一定唷
  • 六角合作的公司 Fable

問題6：台灣、日本前端工作差異

  • 沒待過日本，所以不多做解釋
  • 轉職難易度，前端想從哪邊投入
    Html/CSS/JS/VUE
  • 建議多投入哪部分
    完整轉職路徑也可以參考 六角學院 — 邁向前端工程師 / 設計師之路

問題7：JS要學到什麼程度再進入VUE會較適合？
處理資料 — 陣列方法 物件取值賦值
CRUD — 經典作品JS待辦清單 (四個行為)，要熟練新增、 讀取、 刪除、 修改
資料 — JSON AJAX

問題8：要投入多少時間轉職為前端？
真的很不一定，每個人狀況不一樣，需要熱情，感到樂趣，才能加速學習，但通常需投入六個月到十二個月時間（依六角學院的課程做規劃）
有美術背景除了前端工程師之外還可以有另外兩種路(UI / 網頁設計)可以選擇

問題9：學會JS後會對SEO很有感？
電商必備、廣告操作、大數據

問題10：AI 演算法 ?
數據化、大數據

問題11：很多公司遠端開發需求上升 ?
回歸到服務本質，六角學院已經轉型為半遠端公司，溝通、協作、同步是問題

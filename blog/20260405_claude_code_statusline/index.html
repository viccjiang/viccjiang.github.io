實作紀錄 Statusline 狀態列 + 附加番外篇之隱藏彩蛋 /buddy

在這個客製化狀態列出現之前我一直都是切換 /usage 監測我當下使用量，怕一個 token 不夠，心驚膽顫的，還剩多少 token 撐得過今天這個 issue MR 嗎…

後來在 threads 看到有分享這個功能，發現這個好東西，立刻實作，這樣就不用一直跳出去手動查，資訊一直在眼角視野裡，專注度也高很多。

實作紀錄

Claude Code 的 /statusline 指令可自訂終端機底部的狀態列，即時顯示模型名稱、用量、Git 分支等開發資訊。

設定方式

  1. 在 Claude Code 中輸入 /statusline，依照提示選擇自動配置或手動設定
  2. 設定會寫入 ~/.claude/settings.json，範例如下：

json

{
  "statusLine": {
    "type": "command",
    "command": "bash C:/Users/USER/.claude/statusline-command.sh"
  }
}
  1. 對應的腳本存放於 ~/.claude/statusline-command.sh

我的 Statusline 腳本

( prompt 依照自己希望的狀態列顯示方式寫即可，他會直接幫你寫好 statusline-command.sh)

腳本共顯示三行資訊：

  • 第一行：模型名稱 ｜ context window｜ 專案目錄（Git 分支）
  • 第二行：5 小時用量進度條 + 重置時間
  • 第三行：7 天用量進度條 + 重置時間

進度條以圓點呈現，並依用量百分比動態變色：

用量範圍顏色< 60%🟢 綠色60 ~ 80%🟡 黃色> 80%🔴 紅色

腳本透過 jq 解析 Claude Code 傳入的 JSON 資料，擷取模型名稱、語境視窗使用率、速率限制等欄位，再組合成格式化輸出。

前置需求：安裝 jq

jq並非內建工具，請依照作業系統選擇對應的安裝方式：

  • macOS：brew install jq
  • Ubuntu / Debian：sudo apt install jq
  • Windows（WSL）：sudo apt install jq
  • Windows（原生）：choco install jq（需先安裝 Chocolatey）

顯示效果

Claude Opus | 📝 45% | myproject (main*)
current ●●●●○○○○○○ 40%  ○ 14:30
weekly  ●●○○○○○○○○ 20%  ○ 04/07 09:00

番外篇：隱藏彩蛋 /buddy

Claude Code 內藏一個彩蛋指令 /buddy，可以召喚一隻專屬的「coding 夥伴」陪你 coding，純粹娛樂性質，大家開始曬 claude code 寵物，於是有人還稱之為 🐾 寵物展 🐾 ( ㄏ ㄟ ˊ ~~~ 另類寵物展，脆友們總是創意十足 )

使用方式

在 Claude Code 中輸入：

/buddy

系統會隨機召喚一隻夥伴，以卡片形式顯示其名字、稀有度、類型、個性描述與屬性數值。

卡片範例

以我自己首抽 Warble（幽靈型）為例：

稀有度：⭐⭐ UNCOMMON
類型：GHOST

這是 claude code 給我的解釋

一隻有耐心的幽靈，會在你 debug 時輕聲哼歌，享受幫你理清思路的過程，
但偶爾會被牠覺得好笑的程式碼註解分心。

DEBUGGING  ░░░░░░░░░░  9       除錯能力
PATIENCE   ██████████  87      耐心
CHAOS      █████░░░░░  52      混沌值
WISDOM     ██░░░░░░░░  17      智慧
SNARK      ████░░░░░░  46      毒舌度

不過這個數值組合真的很有趣 😂

  • 耐心 87 但除錯能力 9 — 牠陪你 debug 陪得超有耐心，但根本不會 debug，純粹精神支持
  • 智慧 17 — 不聰明但充滿自信
  • 毒舌 46 — 偶爾會酸你一下但又不太狠

是個會在旁邊哼歌、看到你的爛註解忍不住笑出來、然後給你一個「加油喔」的靈體夥伴 👻

互動指令

指令說明/buddy召喚夥伴說出夥伴的名字與牠互動，

聽聽牠的看法/buddy pet摸摸牠 🐾

/buddy off關閉夥伴

夥伴不會佔用你的 token 用量。
